Este repositorio contiene la implementación del juego **Candy Crush** desarrollado en Java. Es un juego de puzzle en el que el objetivo es alinear tres o más caramelos iguales para eliminarlos del tablero y sumar puntos.

## Descripción

CandyCrush es un juego clásico de combinación de piezas donde el jugador intercambia caramelos adyacentes para formar líneas horizontales o verticales de igual color. Al eliminar estas combinaciones, nuevos caramelos caen desde arriba, permitiendo nuevas jugadas.

## Tecnologías utilizadas

- Java (JDK 11 o superior recomendado)
- Para usar la libreria json: click derecho en el proyecto -> configure build path -> libraries -> class path -> add jars -> buscar en la carpeta librerias -> seleccionar jar -> apply and close (En eclipse)
